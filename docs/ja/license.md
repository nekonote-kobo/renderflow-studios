# ライセンス

RenderFlow Studios（以下「本ソフトウェア」）は Adacchi-MultiCreator が著作権を保有する有償ソフトウェアです。購入者は以下の条件で本ソフトウェアを使用できます。

## 許可されること

- 購入者本人が所有・管理する複数の端末にインストールし、使用すること
- 本ソフトウェアを使用して制作した画像・映像・その他の成果物を、個人・商用を問わず自由に公開・販売すること
- 自身の用途のために `DB/` 内の JSON・アイコンを編集すること

## 禁止されること

- 本ソフトウェア（一部を含む）の再配布、転売、貸与、共有
- ライセンスキーの第三者への譲渡・公開
- ライセンス認証の回避、または認証機構の改変
- リバースエンジニアリングを目的とした解析（自身の用途でのソース閲覧・修正は妨げません）

## 免責

本ソフトウェアは現状有姿で提供されます。本ソフトウェアの使用によって生じたいかなる損害についても、作者は責任を負いません。

## サポートとアップデート

購入者は、購入したメジャーバージョン（v1.x）内のアップデートを無償で受け取れます。サポートは GitHub Issues および購入元の連絡先を通じて提供します。

## 第三者ライブラリ

本ソフトウェアは Blender の Python API のみを使用しており、追加の外部ライブラリを含みません。
