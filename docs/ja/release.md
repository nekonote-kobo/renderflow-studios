    現在は **限定モニター向けの α 版** です。ご協力いただいている方にのみ配布しており、仕様・UI・プリセット内容は正式リリースまでに変更される場合があります。不具合や要望は [ヘルプ](help.md) の窓口までお知らせください。

## v1.0.0-alpha <small>2026-09</small>

限定モニター向け α 版（初回配布）。

**レンダースタイル**

- 5 種のプリセット（1980年代前半 / 後半、1990年代-A / B、映画風）
- 出力 / 品質 / ライン の 3 セクションで適用後の値を確認・微調整
- プリセットにセーフエリア余白（`safe area px`）を追加
- マイプリセット（現在の設定をパネルから保存・削除、サムネイル変更）

**カメラ**

- カメラ選択、投影方式、レンズ、被写界深度をサイドバーで操作
- ガイド（セーフエリア / レイアウトガイド）をカメラごとに保持
- レンズ詳細・ガイドをサブパネル化

**コンポジットレイヤー**

- 入力 / 調整 / フィルター / Look / マスク / グループ の 6 種のレイヤー
- 調整レイヤー 6 種、FX フィルター 22 種、Look プリセット 9 種
- ドラッグ並べ替え HUD、複製、削除、ソロ、クリッピング、Before / After

**その他**

- 日本語 / 英語 UI
- ライセンス認証（申請・認証・オフラインキャッシュ）
