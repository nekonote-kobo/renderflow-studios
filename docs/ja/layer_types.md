# レイヤーの種類

**レイヤーを追加** メニューから追加できるレイヤーの一覧です。

| 種別 | 内部ノード | 用途 |
|---|---|---|
| **入力 (Input)** | Render Layers / Image / Movie Clip | 合成の素材。シーン（レンダーレイヤー）、画像、連番画像、動画クリップ |
| **調整 (Adjustment)** | 色調補正ノード | 明るさ・露出・カラーバランス・カーブ・色相彩度・ガンマ |
| **フィルター (Filter)** | ノードグループ（アセットライブラリからアペンド） | ブラー、グロー、色収差、NPR、レトロなどの効果 |
| **Look / プリセット** | ノードグループ | 複数ノードを組み合わせた仕上がりの雛形 |
| **マスク (Mask)** | Ellipse / Box / Double Edge Mask / Image | 効果の適用範囲を制限 |
| **グループ (Group)** | ― | 複数レイヤーをまとめて不透明度・表示を制御 |

## 入力レイヤー

| ソース | 説明 |
|---|---|
| シーン（レンダーレイヤー） | 現在のシーンのレンダー結果。ビューレイヤーを選択できます |
| 画像 | 単一の画像ファイル |
| 連番画像 | `name_0001.png` 形式の連番。フレーム数と開始フレームを指定 |
| 動画クリップ | 動画ファイル |

複数の入力レイヤーを重ね、ブレンドモードで合成できます（例：実写プレートの上に 3D をスクリーン合成）。

## グループ

グループにまとめると、内部のレイヤー全体に対して不透明度とマスクを一括で適用できます。
「調整 + フィルター + マスク」のセットをグループにしておくと、効果単位で ON / OFF できて便利です。
