# Release Notes

!!! warning "About the alpha"
    This is currently a **closed alpha for invited testers only**. It is distributed solely to participating monitors, and features, UI and preset contents may change before the official release. Please report bugs and requests via the channels listed in [Help](help.md).

## v1.0.0-alpha <small>2026-09</small>

Closed alpha for invited testers (first build).

**Render Style**

- 5 presets (1980s Early / Late, 1990s-A / B, Cinema Style)
- Output / Quality / Lines sections to review and tune applied values
- `safe area px` added to presets
- My Presets (save / delete current settings from the panel, custom thumbnails)

**Camera**

- Camera selection, projection, lens and depth of field in the sidebar
- Guides (safe areas / layout guides) stored per camera
- Lens Details and Guides as sub-panels

**Compositor Layers**

- 6 layer types: Input / Adjustment / Filter / Look / Mask / Group
- 6 adjustment types, 22 FX filters, 9 Look presets
- Drag-reorder HUD, duplicate, remove, solo, clipping, Before / After

**Other**

- Japanese / English UI
- License activation (request, verify, offline cache)
