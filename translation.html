    Size of the blocks used to draw fog and smoke. Small = fine, smooth fog (slower). Large = chunky, blocky fog (fast, retro look) Size of the blocks used to draw fog and smoke.     Let fog and smoke cast shadows on themselves and on objects. Makes thick fog look solid. Off is faster Let fog and smoke cast shadows on themselves and on objects. Makes thick fog look solid. Off is faster 霧や煙が自分自身や物体に影を落とすようにします。濃い霧に立体感が出ます。OFFのほうが速い
    Quality of the shadows inside fog. Higher = smoother, slower. Only used when Volume Shadows is on Quality of the shadows inside fog. Higher = smoother, slower. Only used when Volume Shadows is on 霧の中の影の品質。高いほどなめらかで遅くなります。ボリュームの影がONのときだけ使われます
    Distance between fog samples when rendering. Smaller = more detail but slower. 0.5 = high quality, 4 = fast and rough Distance between fog samples when rendering. Smaller = more detail but slower. 0.5 = high quality, 4 = fast and rough レンダリング時に霧を計算する間隔。小さいほど細かく遅くなります。0.5＝高品質、4＝速いが粗い
    Same as Step Rate Render, but for the 3D viewport preview. Keep it larger than the render value to keep the viewport fast Same as Step Rate Render, but for the 3D viewport preview.     How many times light can scatter inside fog. 0 = light passes straight through (fast). 1+ = glowing, milky fog (slower) How many times light can scatter inside fog. 0 = light passes straight through (fast). 1+ = glowing, milky fog (slower) 霧の中で光が散乱する回数。0＝光がそのまま通り抜ける（速い）、1以上＝乳白色に光る霧（遅い）
